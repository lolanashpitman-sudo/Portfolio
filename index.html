The Morning
Board

A personal front page I designed and built with Claude. Every morning it rebuilds itself with the news, fashion, and culture I follow, a mood board pulled from my Pinterest, and a job board that matches openings to my own experience.

  • ProblemTen tabs every morning: news, runway coverage, job boards, weather. None of them talked to each other.
  • BuildI vibe coded it: I directed the design and logic while artificial intelligence handled the code and daily research. A scheduled run rewrites one data block each morning, so the layout stays fixed while the content stays current.
  • HighlightsJob cards explain why each role fits my background · outfit suggestion from the weather · filterable by field
  • NowI use it every morning and keep refining it around what I’m really looking for. One known limit: it can’t pull from The New York Times, so I still read that separately.

Blackbird Labs · Summer 2026

NEST

Materials request system

NEST is an inventory tracking and request management system I built with Claude Code: a web app where staff submit and track material requests, connected to a custom Slack integration that routes every request to a private approval channel with interactive approve and deny buttons.

  • ProblemRequests for event and branded materials came in through Slack DMs, where they got lost, or in person, where they piled up. A small but growing team needed one organized way to ask.
  • UsersThe whole company, about 50 people, uses it whenever they need materials for an event or internal branded merch.
  • BuildI met with my manager to define the functions she needed and how it should look, then built it: submit a request, approve or deny it, update inventory counts, and reorder items.
  • ApprovalsEach request posts approve and deny buttons to a private Slack channel, so only approved team members can sign off on removing materials.
